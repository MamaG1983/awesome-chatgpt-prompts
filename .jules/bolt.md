## 2026-07-30 - O(N) Card Filtering and Singleton Promise Caching
**Learning:** Repetitive fetching and parsing of prompts.csv/vibeprompts.csv on every audience switch or search input keystroke represents a severe main-thread and network bottleneck. Additionally, iterating over cards and searching the raw prompts array on every filter operation causes an O(N^2) operation that results in layout and execution jank. Caching fetching/parsing via a singleton promise pattern, and encoding metadata inside DOM datasets (dataset.forDevs) allows extremely fast, constant-time visibility toggling and zero network overhead.
**Action:** Always implement a singleton promise pattern to cache resource fetch and parse results on static applications. Cache component state or metadata using dataset attributes on elements to enable fast O(N) lookups instead of nested O(N^2) search loops.
