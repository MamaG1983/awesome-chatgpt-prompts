## 2026-07-27 - Awesome ChatGPT Prompts CSV Cache & O(N) Toggling
**Learning:** Parsing the large `prompts.csv` and `vibeprompts.csv` files repeatedly on user interaction (search keystrokes or audience toggles) causes severe main-thread lag. Additionally, querying and matching titles of DOM nodes against CSV arrays dynamically in a search loop leads to an O(M * N) complexity that is extremely inefficient. Implementing a singleton promise for data fetching ensures single-request, single-parse per session caching, with retry on failure. By appending `data-for-devs` attributes on the cards during render time, audience toggling is reduced to O(N) DOM mutations.
**Action:** Use a singleton promise pattern for async loading of application data. Use semantic HTML and `data-*` metadata attributes on DOM elements during construction to fast-track subsequent filtering and state changes to O(N).
