## 2026-08-05 - Singleton Promise Caching for Static Assets & CSV Parsers
**Learning:** Re-fetching and re-parsing large CSV static files (`prompts.csv` (~113KB) and `vibeprompts.csv` (~29KB)) on load or, worse, on every search keypress inside input listeners causes significant network and CPU overhead. Caching the raw fetch call using a Singleton Promise Pattern prevents redundant fetches and duplicate parsing across the application life cycle. Furthermore, when implementing cache layers on collections, always clone arrays before performing operations like `.sort()` (e.g., `[...await getPrompts()].sort()`) to prevent unintended mutation of the cached singleton data structure.
**Action:** Use Singleton Promise Caching for any asynchronously loaded application configuration or static data files, and ensure local sorting/mutations do not pollute the shared promise-cache.
