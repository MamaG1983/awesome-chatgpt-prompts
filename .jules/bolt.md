## 2026-10-16 - Singleton Promise Caching for Prompts CSV Data
**Learning:** Repeated fetching and parsing of large CSV files (`/prompts.csv`, ~113KB) on interactive DOM events (such as switching audience selectors or re-filtering prompts) creates redundant network requests, unnecessary main-thread CSV parsing, and allocations. Implementing a singleton promise pattern (`getPrompts()`) guarantees a single fetch and parse operation across the application lifecycle. Sorting operations on cached arrays should always operate on shallow copies (`[...prompts].sort()`) to avoid mutating shared state across caller functions.
**Action:** Always wrap application-wide static/data fetches in a singleton promise cache function (`getPrompts()`) that pre-computes lowercased/normalized properties (`actLower`, `promptLower`, `cleanTitle`) for O(1) string comparison during filtering loops.
