## 2026-10-31 - Singleton Promise Pattern for Static CSV Asset Caching
**Learning:** In static Jekyll client-side applications where raw data files (like `prompts.csv` and `vibeprompts.csv`) are loaded and parsed directly in JavaScript, user interactions (e.g., audience switching, search input, rendering loops) can trigger multiple concurrent or redundant network fetches and expensive regex CSV parsings (~5ms CPU blocking time each).
**Action:** Use a singleton promise caching pattern (`let dataPromise = null; function getData() { if (!dataPromise) dataPromise = fetch(...)...; return dataPromise; }`) with error handling resetting the cache on failure. When performing in-place operations like sorting, always operate on a cloned array (`[...data].sort()`) to avoid mutating cached collections across callers.
