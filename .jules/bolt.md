## 2026-07-23 - Singleton Promise Caching for Static CSVs
**Learning:** In a Jekyll static site using CSV files (like prompts.csv and vibeprompts.csv) as a client-side database, repeated fetch and parse operations during user actions (like keypresses on search or audience filtering toggles) create massive main-thread layout thrashing and network bloat. A promise-based singleton pattern is extremely effective here because a single promise can cache both the HTTP response and the parsed JS object arrays, resolving instantly on subsequent requests and entirely preventing duplicate network requests.
**Action:** Use a singleton promise pattern (`getPrompts()`) with custom error handlers that reset the promise to null on failure to allow retries. Always clone arrays before mutating operations (like sorting) to prevent side effects on other components sharing the same promise cache.
