## 2025-07-31 - Singleton Promise Caching for Static CSV Prompts
**Learning:** In static-hosted sites like Awesome ChatGPT Prompts, parsing relatively large CSV datasets (~113KB prompts.csv and ~29KB vibeprompts.csv) on every keystroke, filter toggle, or render cycle can block the main thread and cause visible UI lag, alongside redundant network requests. Mutating the cached array directly (e.g., in-place sorting) can also introduce bugs or unexpected UI states due to side-effects.
**Action:** Implement a singleton promise pattern cache (`getPrompts()` in script.js and `loadPrompts()` in vibe/script.js) that resolves to the parsed CSV array once per session, and reset the promise to null in a catch block on failure. Always clone the returned cached array before mutating or sorting (e.g. `[...await getPrompts()].sort(...)`).
