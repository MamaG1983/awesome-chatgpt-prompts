## 2025-02-15 - Singleton Promise Pattern for Static Asset Caching
**Learning:** Fetching and parsing static files (like large CSVs) repeatedly on frequent user interactions (such as search keystrokes or layout changes) creates significant main-thread blockages and redundant network requests. Caching the raw network promise rather than the resolved results guarantees that multiple concurrent requests only trigger a single fetch and parsing operation. Additionally, clone operations (e.g. `[...array]`) are critical before sorting to prevent mutating the shared cached reference.
**Action:** Always implement singleton promise cache pattern for CSV and JSON resources that do not change during the session, and always deep-copy/shallow-copy the array before in-place mutations like `.sort()`.
